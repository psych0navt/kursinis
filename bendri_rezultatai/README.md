# Bendri eksperimentų rezultatai

Keturi modeliai, du duomenų rinkiniai, aštuoni eksperimentai.

Atidarykite `ataskaita.html` naršyklėje. Grafikai pateikti PNG ir PDF formatais.
Visi šeši grafikai viename dokumente: `bendras_palyginimas.pdf`.
Skaitiniai duomenys: `bendra_suvestine.csv` ir `bendra_suvestine.json`.

Kursiokų šaltinių aplankas `kursioku/` neįtraukiamas į Git. Suvienodintos jų rezultatų eilutės įtrauktos į bendrą suvestinę.

Klaidų matricoms ir bendroms mokymo kreivėms trūksta kitų modelių skaitinių matricų / prognozių ir epochų istorijos. Laikai priklauso nuo paleidimo sąlygų, modelio failo dydis — nuo išsaugojimo formato.
